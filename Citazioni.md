# Esercizio 05: Blockquotes (Citazioni)

In Markdown le citazioni o i blocchi di testo in evidenza si creano anteponendo il simbolo maggiore di (`>`) all'inizio della riga.
* **Blocco singolo**: `> Questo è un blocco di citazione.`
* **Blocchi nidificati**: si usano più simboli `>` di seguito (es. `>>` per un secondo livello di rientro).
* **Paragrafi multipli nella citazione**: si mantiene il simbolo `>` anche sulle righe vuote intermedie.

Modifica i 3 testi formali sottostanti seguendo le istruzioni riportate nei commenti.
